要点：パソコンのアプリ（会場の Wi-Fi で使う版）では、音声やイベントの情報はホストの PC と参加者の端末の間だけでやり取りされ、開発者のサーバーには何も送られません。ブラウザ版（cloudmiclive.com）では、やり取りの中継に Cloudflare を使いますが、中身は保存しません。音声は通常保存されず、有料プランの録音機能を使ったときだけ、ホストのパソコンの中にファイルとして残ります。

1. このアプリがすること

CloudMic Live は、同じ Wi-Fi 内にあるスマートフォンをマイクとして使い、イベントの発言（申請・許可・ミュートなど）をホストのパソコンで管理するアプリです。ホスト用アプリはパソコンの中に小さなサーバーを立ち上げ、参加者はスマートフォンのブラウザからそのサーバーに接続します。ブラウザ版（https://cloudmiclive.com）では、インストールなしで、インターネット経由でも使えます。

2. 扱う情報

  • 表示名：参加者が参加時に入力した名前。ホストの画面と、同じイベントの参加者の画面に表示されます。
  • 音声：参加者が「発言を開始」している間だけ、マイクの音声がホストのパソコンへ送られ、その場で再生されます。
  • イベントの進行状態：発言の申請・許可、ミュート、リアクション、早押しの順位など。
  • 接続のための情報：イベントID、合言葉（設定した場合）、端末の一時的な識別子（参加者を区別するためにブラウザ内で作られるランダムな文字列）。

3. 保存と送信

  • パソコンのアプリ（会場の Wi-Fi で使う版）では、上記の情報はホストのパソコンと参加者の端末の間だけでやり取りされます。開発者のサーバーや外部のサービスには送られません。
  • 音声は通常、その場で再生されるだけで保存されません。ホストが有料プランの録音機能を使った場合に限り、ホストのパソコンの中にだけ音声ファイルが保存されます（開発者や外部には送られません）。録音中は参加者の画面に「録音中」と表示されます。発言ログ（誰がいつ何秒話したか）も同様にホストのパソコンの中だけに残ります。
  • イベントの進行状態は、ホストのブラウザ内にそのイベントの間だけ一時保存され、イベントを終えるか画面を閉じると消えます。参加者の端末にも、名前や一時的な識別子がブラウザ内に一時保存されます。
  • 合言葉はホストのパソコンの中でだけ照合され、参加者の端末には配られません。

ブラウザ版（cloudmiclive.com）で使うとき

ブラウザ版は、インストールなしでインターネット経由で使える版です。ホストの画面と参加者の画面のやり取りを中継するために、Cloudflare, Inc.（米国）のサービス（Cloudflare Workers・Durable Objects・Realtime TURN）を使っています。

  • 合図の中継：表示名や、発言の申請・許可などのやり取りは、Cloudflare のサーバーを通ってホストと参加者に届きます。中継するだけで、中身は保存しません。
  • 部屋の記録：部屋が開いている間だけ、部屋の ID・終わる時刻・試用かプロか・ホストの鍵の指紋（鍵そのものではありません）・参加者の一時的な識別子を Cloudflare に置きます。部屋が終わると消します。
  • 音声：参加者の端末からホストの端末へ直接送ります。直接つながらないとき（スマートフォンのモバイル回線など）は Cloudflare の中継（TURN）を通りますが、暗号化されていて中身は読めず、保存もしません。
  • 接続元の住所（IP アドレス）：無料の試用の回数を数え、使いすぎを防ぐために、IP アドレスを秘密の値と混ぜて元に戻せない形（指紋）にしたものだけを、最長 2 日ほど置きます。IP アドレスそのものは置きません。
  • 使った量の記録：1 日ごとの部屋の数・メッセージの数・つないでいた時間などの合計だけを、運営のために 45 日まで置きます。名前や話した内容は含みません。
  • 動作の記録（ログ）：不具合を調べるために、受け付けの記録の一部（日時・アクセスした場所・結果など）を、Cloudflare のログの機能に短い期間（数日）置きます。Cloudflare の仕組みとして、接続元の情報が含まれることがあります。
  • プロのライセンスキー：プロの部屋を作るとき、有効かどうかを確かめるために送られます。確かめるだけで、保存しません。

Cloudflare での取り扱いは、Cloudflare のプライバシーポリシー（https://www.cloudflare.com/privacypolicy/）にも従います。

4. 利用しない情報

位置情報、連絡先、写真、アカウント情報などは取得しません。利用状況の分析や広告のための外部サービス（解析ツール・広告ネットワーク）は、アプリにもブラウザ版にも組み込んでいません。無料版の参加者画面に表示される案内は、アプリに同梱された自社の案内だけで、外部からの読み込みはありません。

この Web サイトについて

この紹介サイト（845labdevelopment-sys.github.io）では、ページの訪問数を知るために Cloudflare Web Analytics を使っています。Cookie を使わず、端末の識別子や個人を特定できる情報は集めません（ページの URL、参照元、ブラウザの種類、おおまかな地域だけが集計されます）。アプリ本体には、この計測を含め、外部の解析サービスは一切入っていません。

5. マイクの許可

参加者が発言するには、ブラウザでマイクの使用を許可する必要があります。許可はいつでも端末の設定から取り消せます。マイクが使われるのは「発言を開始」してから「発言を終了」するまでの間だけです。

6. 購入について

有料プラン（イベントパス・月額／年額）の購入は、アプリを配布するストアの仕組みで処理されます。開発者がクレジットカード番号などの決済情報を受け取ることはありません。ブラウザ版では、今は購入できません（プロは、アプリで購入したライセンスキーで使えます）。

7. 子どもの利用

このアプリは特定の年齢層に向けたものではなく、メールアドレスや電話番号などの個人情報を集めないため、年齢にかかわらず利用できます。学校などで使う場合は、主催者が参加者の表示名の扱いに配慮してください。

8. 変更と連絡先

このポリシーを変更するときは、このページを更新し、最終更新日を改めます。ご質問は 845labsupport@gmail.com までお寄せください。
