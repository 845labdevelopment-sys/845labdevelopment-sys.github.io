Android と Windows でクリップボードを共有

機種を選ばず、同じ Wi‑Fi だけで · 2026年10月6日

Android でコピーした文を Windows で貼りたい、Windows でコピーした文を Android で使いたい。このページでは、Android と Windows の間でクリップボードを共有する方法を説明します。

Microsoft の「スマートフォン連携」で足りる人・足りない人

Windows の「スマートフォン連携（Phone Link）」には「デバイス間のコピーと貼り付け」があります。ただし Microsoft サポートの案内で対応機種として挙がっているのは、Samsung（One UI 2.1 以降）や HONOR・OPPO・ASUS・vivo・Xiaomi の一部機種です（2026年10月時点）。それ以外の機種（たとえば Pixel や AQUOS など、一覧に無いもの）では、この機能が使えません。

対応機種でない人や、インターネットを通さず手元の Wi‑Fi の中だけで済ませたい人は、次の方法が使えます。

AirBoard を使う方法

AirBoard は、同じ Wi‑Fi（LAN）につながった端末どうしで、コピーした文・写真・ファイルを直接やり取りするアプリです。機種を選ばず、アカウント登録もいりません。

準備（最初の 1 回だけ）

  1. Windows に Microsoft Store から、Android に Google Play から AirBoard を入れます。
  2. Windows と Android を同じ Wi‑Fi につなぎます。
  3. Android で「Wi‑Fiで探す」を押すか QR コードを読み取って、PC を選びます。はじめての端末は、Windows 側で承認するとつながります。

Windows でコピー → Android で貼り付け

Windows でいつもどおりコピー（Ctrl+C）するだけで、Android のクリップボードに入ります。設定の「バックグラウンド接続を維持」（初期設定でオン）が動いていれば、AirBoard を開いていなくても届きます。

Android でコピー → Windows で貼り付け

Android でコピーしたあと、AirBoard を開きます。最新のコピーが Windows に届き、Windows のクリップボードに入ります（Android 10 以降は、裏に回ったアプリがクリップボードを読めない仕組みのため、AirBoard を開いたときに送ります）。「共有」タブの「いまのコピー」から送ることもできます。

ほかのアプリの「共有」メニューから AirBoard を選ぶと、文やファイルを AirBoard に取り込めます。文は入力欄に、ファイルは送信待ちに入るので、確かめてから送ります。

写真やファイルも

  • Android → Windows：「共有」タブの「写真」か「ファイル」から選ぶと、すぐ送られます。Windows では「ドキュメント」の中の AirBoard フォルダに入ります（保存先は変えられます）。
  • Windows → Android：ファイルを AirBoard のウィンドウに落とすだけです。Android では「ダウンロード」の中の AirBoard フォルダに入ります。

届かないときは、電池の最適化を確認してください。機種によっては、電池を長持ちさせる設定でアプリの裏での動きが止められることがあります。その場合は、Android の設定で AirBoard の電池の最適化を外すか、AirBoard を開いてから使ってください。

PC が無くても

Android は AirBoard の「Hub」になれます。PC が無くても、Android と iPhone の間でコピーや写真をやり取りできます（設定の「PCなし接続モード（スマホ Hub）」、初期設定でオン）。

つながらないとき

会社・学校・ホテルの Wi‑Fi では、端末どうしの通信が止められていることがあります。ホットスポットでつなぐ方法をご覧ください。
