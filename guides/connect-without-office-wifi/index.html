会社の Wi‑Fi でつながらないときは

ホットスポット・インターネット共有でつなぐ · 2026年10月6日

AirBoard は、同じ Wi‑Fi につながった端末どうしで直接やり取りします。ところが会社・学校・ホテル・カフェの Wi‑Fi では、安全のために端末どうしの通信が止められていることが多く、同じ Wi‑Fi にいてもつながらないことがあります。

そんなときは、Windows の「モバイル ホットスポット」かiPhone の「インターネット共有」で、自分の端末だけの小さなネットワークを作ると使えます。どちらも 2026 年 10 月に、Windows 10 の PC と iPhone で動くことを確かめました。

先に確認してください。会社や学校の PC・スマホでは、ホットスポットやインターネット共有がルールで禁止されていたり、設定で使えなくなっていたりします。使ってよいか分からないときは、管理者に確認してください。

おすすめ：Windows のモバイル ホットスポットに iPhone をつなぐ

いちばん手軽で、設定の変更もいりません。

  1. Windows で「設定」›「ネットワークとインターネット」›「モバイル ホットスポット」を開き、オンにします。表示されるネットワーク名とパスワードを確かめます。
  2. iPhone の「設定」›「Wi‑Fi」で、そのネットワークを選んでつなぎます。
  3. Windows と iPhone で AirBoard を開き、iPhone で「Wi‑Fiで探す」を押して PC を選びます。

確かめた範囲では、QR や手動の入力はいらず、そのままつながりました。iPhone から PC へテキスト・写真・クリップボード、PC から iPhone へテキスト・ファイルが届きました。PC が Wi‑Fi につながったままでも、ホットスポットを出せました（PC の Wi‑Fi の機能によっては使えないことがあります）。

iPhone のインターネット共有に PC をつなぐ

  1. iPhone の「設定」›「インターネット共有」をオンにします。
  2. Windows で、iPhone の名前のネットワークにつなぎます。
  3. Windows で、そのネットワークを「プライベート」にします。「設定」›「ネットワークとインターネット」›「Wi‑Fi」› iPhone の名前のネットワーク ›「ネットワーク プロファイル」で「プライベート」を選びます（Windows 11 では「ネットワーク プロファイルの種類」）。
  4. AirBoard を開いてつなぎます。

「パブリック」のままだと、つながりません。Windows は新しいネットワークを「パブリック」として扱うことが多く、そのままだと「Wi‑Fiで探す」・QR・手動のどれでもつながりませんでした。自分の iPhone のネットワークなら、「プライベート」にして問題ありません。

「プライベート」にしたあとは、テキスト・写真・クリップボード・ファイルが両方向に届きました。

それでもつながらないとき

  • Windows と iPhone の両方で、AirBoard を開いているか確かめてください（iPhone は AirBoard を開いている間だけ送受信します）。
  • はじめての端末は、Windows 側で承認するとつながります。
  • ウイルス対策ソフトのファイアウォールが、受信を止めていることがあります。
  • 解決しないときは、アプリの「設定」›「接続診断」の内容を添えて、845labsupport@gmail.com までお送りください。
