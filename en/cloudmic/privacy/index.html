In short: in the desktop app (used on the venue's Wi-Fi), audio and event data stay between the host's PC and the participants' devices, and nothing is sent to the developer. What the app does

CloudMic Live turns smartphones on the same Wi-Fi network into microphones and lets the host manage who speaks (requests, permissions, mute) from a PC. The host app runs a small server on the PC; participants connect to it from their phone's browser. The browser version (https://cloudmiclive.com) works over the internet without installing anything.

Information handled

  • Display names entered by participants
  • Microphone audio while a participant is actively speaking
  • Event state (speech requests, permissions, mute, reactions, buzzer order)
  • Connection details (event ID, optional passcode, a random temporary identifier created in the browser to tell participants apart)

Storage and transmission

In the desktop app, all of this stays between the host's PC and the participants' devices on the local network. Nothing is sent to the developer or to third-party services. Audio is normally played back live and not stored. Only when the host uses the recording feature of a paid plan is an audio file saved, and only on the host's own PC; nothing is sent to the developer or any server. While recording, every participant's screen shows a "Recording" indicator. The speech log (who spoke when and for how long) likewise stays on the host's PC. Event state is kept temporarily in the host's browser for the duration of the event. The passcode is checked only on the host's PC and is never distributed to participants.

When you use the browser version (cloudmiclive.com)

The browser version works over the internet without installing anything. To relay messages between the host's screen and participants' screens, it uses services from Cloudflare, Inc. (United States): Cloudflare Workers, Durable Objects and Realtime TURN.

  • Message relay: display names and event messages (speech requests, permissions and so on) pass through Cloudflare's servers on their way between the host and participants. They are relayed only and their content is not stored.
  • Room record: only while a room is open, we keep the room ID, its end time, whether it is a trial or Pro room, a fingerprint of the host key (not the key itself) and the participants' temporary identifiers on Cloudflare. They are deleted when the room ends.
  • Audio: sent directly from the participant's device to the host's device. When a direct connection is not possible (for example on a phone's mobile network), it passes through Cloudflare's relay (TURN); it is encrypted, cannot be read there, and is not stored.
  • IP address: to count free trials and prevent abuse, we keep only an irreversible fingerprint of the IP address (mixed with a secret value) for up to about 2 days. The IP address itself is not kept.
  • Usage totals: we keep only daily totals (number of rooms, number of messages, connected time and so on) for up to 45 days to run the service. They contain no names or speech content.
  • Logs: to investigate problems, a sample of request records (time, path, result and so on) is kept for a short period (a few days) in Cloudflare's logging feature. By the way Cloudflare works, these may include information about where the connection came from.
  • Pro license key: sent when creating a Pro room so that its validity can be checked. It is checked only, not stored.

Cloudflare's handling is also subject to Cloudflare's privacy policy (https://www.cloudflare.com/privacypolicy/).

Information not used

No location, contacts, photos or account data. No analytics or advertising SDKs, in either the app or the browser version. The notice shown on the participant screen in the free tier is bundled with the app and loads nothing from the internet.

About this website

This website (845labdevelopment-sys.github.io) uses Cloudflare Web Analytics to count page visits. It sets no cookies and collects no device identifiers or personal information (only page URL, referrer, browser type and approximate region are aggregated). The app itself contains no analytics of any kind, including this one.

Microphone permission

Participants grant microphone access in their browser and can revoke it at any time in their device settings. The microphone is used only between "Start speaking" and "Stop speaking".

Purchases

Paid plans are processed by the store that distributes the app. The developer never receives payment details. The browser version currently has no purchases (Pro works with a license key bought in the app).

Children

The app is not directed at any particular age group and collects no personal information such as email addresses or phone numbers.
