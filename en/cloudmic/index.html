How it works

Three steps to get started.

1

Create an event on your PC

Launch the app on Windows and create an event. Make sure the PC is on the same Wi‑Fi as your participants.

2

Participants scan the QR code

Show the QR code on screen. Participants scan it with their phone — no install, it opens in the browser.

3

Approve, and they're on

A participant taps "Request to speak". When the host allows it, their voice plays from the PC.

Privacy

Voices stay in the room.

Audio and event data travel only between the host's PC and the participants' devices on the local network. Nothing is sent to the developer or to third-party services. Audio is normally played live and not stored; with a paid plan's recording feature it is saved only on the host's PC. There are no analytics or advertising SDKs.

FAQ

Questions

Does everyone need to be on the same Wi‑Fi?

Yes. The host PC and the participants' phones must be on the same Wi‑Fi (or the same LAN). There is no way to join remotely over the internet — which also means no voice or event data ever passes through an outside server.

If the venue's Wi‑Fi blocks devices from talking to each other, you can connect phones to the PC's Mobile hotspot instead.

A security warning appears on the phone the first time it connects

Because CloudMic Live uses the microphone, the host PC serves the page over HTTPS with a certificate it generates itself. That certificate is not issued by a public authority, so the browser warns once on first access. The connection never leaves your local network, so it is safe to proceed.

Android (Chrome)

  1. On "Your connection is not private", tap Advanced
  2. Tap Proceed to (address) (unsafe)

iPhone (Safari)

  1. On "This Connection Is Not Private", tap Show Details
  2. Tap visit this website, then Visit Website to confirm

If it still won't connect, the "?" button on the host screen explains how to use an alternative address.

Is audio recorded?

Normally, no. Only when a host on the monthly or yearly plan uses the recording feature is audio saved, as a file on the host's own PC. While recording, every participant's screen shows a "Recording" indicator. Audio is never sent to the developer or any server.

The microphone is used only between "Start speaking" and "Stop speaking".

Do participants need to install an app?

No. They open the host's QR code in Safari (iPhone) or Chrome (Android). No account is needed, and participants are always free.

What does the host app run on?

Windows 10 (version 1809 or later) and Windows 11. We will add the Microsoft Store link to this page as soon as the app is available.
