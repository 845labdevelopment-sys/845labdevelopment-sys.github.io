「自分に送る」以外で、スマホと PC にメモを渡す

コピーするだけで届く方法 · 2026年10月6日

スマホで見つけた URL や住所を PC で使いたいとき、PC で書いた文をスマホに送りたいとき、LINE やメールで「自分に送る」人は多いと思います。手軽ですが、毎回トークを開いて、送って、PC 側でまた開いて、コピーして……と、意外と手順が多い方法です。

このページでは、自分あての送信を使わずに、スマホと PC の間でメモや URL を渡す方法をまとめます。

よく使われる方法

  • LINE やメールで自分に送る：どの端末でも使えますが、毎回いくつも操作がいり、内容が外のサーバーに残ります。
  • クラウドのメモアプリ：同じアカウントでそろえれば便利ですが、アカウントの設定と同期を待つ時間がいります。
  • OS どうしの連携機能：iPhone と Mac のユニバーサルクリップボードや、一部の Android と Windows のスマートフォン連携など、組み合わせが合えば一番手軽です。組み合わせが合わないと使えません。

コピーするだけで渡す方法（AirBoard）

AirBoard は、同じ Wi‑Fi（LAN）につながった端末どうしで、コピーした文・写真・ファイルを直接やり取りするアプリです。Windows・iPhone・iPad・Android の組み合わせで使えて、アカウント登録はいりません。

  • PC でコピー → スマホで貼る：PC でいつもどおりコピーすると、スマホのクリップボードに届きます（iPhone は AirBoard を開いている間）。
  • スマホでコピー → PC で貼る：スマホでコピーしてから AirBoard を開くと、PC のクリップボードに届きます。PC で Ctrl+V するだけです。
  • 何度も使うものは「ボード」に：住所・電話番号・会議の URL などはボードにピン留めしておけば、ワンタップでコピーできます。
  • あとで探すときは「履歴」：送った・届いた・この端末でコピーした内容が一列に並び、テキスト／ファイル／コピーで絞り込めます。

はじめは、PC とスマホの両方に AirBoard を入れて、同じ Wi‑Fi でつなぐだけです。くわしい手順はiPhone と Windows でコピペする方法、Android と Windows でクリップボードを共有する方法をご覧ください。

どれを選べばいい？

  • たまに 1 つ送るだけ → 自分あての LINE やメールで十分です。
  • 同じメーカーの端末どうし（iPhone と Mac など） → OS の連携機能が手軽です。
  • iPhone と Windows、Android と Windows など、メーカーをまたいで毎日何度もやり取りする → AirBoard のように、コピーするだけで届く方法が向いています。

同じ Wi‑Fi の中だけで動きます。離れた場所の端末には送れません。そのぶん、コピーした内容が外のサーバーに残りません。会社などの Wi‑Fi でつながらないときは、ホットスポットでつなぐ方法があります。

ほかのガイド

  • iPhone と Windows でコピペする方法
  • iPhone の写真をケーブルなしで PC へ
  • Android と Windows でクリップボードを共有
  • 会社の Wi‑Fi でつながらないときは
