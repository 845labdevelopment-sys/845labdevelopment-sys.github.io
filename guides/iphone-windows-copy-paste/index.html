iPhone と Windows でコピペする方法

同じ Wi‑Fi でクリップボードを共有する · 2026年9月29日

iPhone でコピーした URL を Windows で開きたい。Windows で書いた文を iPhone のメッセージに貼りたい。そのたびに自分宛てにメールや LINE を送っていないでしょうか。

このページでは、iPhone と Windows の間でコピー＆ペーストする方法を、標準機能でできること・できないことから順に説明します。

標準機能では、iPhone と Windows のコピペはむずかしい

  • Apple のユニバーサルクリップボードは、同じ Apple アカウントでサインインした Apple 製品（iPhone・iPad・Mac）どうしの機能です。Windows とはつながりません。
  • Microsoft の「スマートフォン連携」は iPhone にも対応していますが、Microsoft サポートの案内で「デバイス間のコピーと貼り付け」の対応機種として挙がっているのは、Android の一部機種です（2026年9月時点）。

そのため、よく使われるのは次のような回り道です。

  • 自分宛てにメール・LINE・チャットを送る
  • クラウドのメモやストレージに貼って、もう片方で開く

どちらも使えますが、毎回いくつも手順があり、コピーした内容が外のサーバーに残ります。

AirBoard を使う方法

AirBoard は、同じ Wi‑Fi（LAN）につながった端末どうしで、コピーした文・写真・ファイルを直接やり取りするアプリです。インターネット上のサーバーを通らず、アカウント登録もいりません。

準備（最初の 1 回だけ）

  1. Windows に、Microsoft Store から AirBoard を入れて開きます。
  2. iPhone に、App Store から AirBoard を入れて開きます。
  3. Windows と iPhone を同じ Wi‑Fi につなぎます。
  4. iPhone で「Wi‑Fiで探す」を使うか、QR コードを読み取って Windows を選びます。
  5. はじめての端末は、Windows 側で承認するとつながります。次からは自動でつながります。

Windows でコピー → iPhone で貼り付け

Windows でいつもどおりコピー（Ctrl+C）するだけで、iPhone に届きます。iPhone で AirBoard を開いていれば、届いた文はそのまま iPhone のクリップボードに入るので、ほかのアプリで貼り付けられます。

iPhone でコピー → Windows で貼り付け

iPhone でコピーしたあと、AirBoard を開きます。最新のコピーが Windows に届き、Windows のクリップボードに入ります。あとは Windows で Ctrl+V するだけです。

AirBoard の「共有」タブにある「いまのコピー」や「ペースト」のボタンから送ることもできます。

写真やファイルも同じように

  • iPhone → Windows：「共有」タブの「写真」または「ファイル」から選んで送ります。Windows では「ドキュメント」の中の AirBoard フォルダに保存されます（保存先は設定で変えられます）。
  • Windows → iPhone：ファイルを AirBoard のウィンドウに落とすだけです。iPhone では「ファイル」アプリの「このiPhone内 › AirBoard」に入ります。

iPhone で使うときの注意

AirBoard を開いている間に動きます。iOS の仕組み上、AirBoard が裏に回っている間は送ったり受け取ったりしません。使うときは AirBoard を開いてください。裏に回っている間に何度かコピーした場合、開いたときに送られるのは最新の 1 件です。

  • 「ペーストしますか？」の確認について：iPhone では、ほかのアプリでコピーした内容を読むときに確認が出ることがあります。毎回出ないようにするには、iPhone の「設定」› AirBoard ›「他のAppからペースト」を「許可」にします。「共有」タブの「ペースト」ボタンから送るときは確認は出ません。
  • 会社や学校の Wi‑Fi：ネットワークの設定で端末どうしの通信が止められていると、つながらないことがあります。その場合はネットワークの管理者に確認してください。

よくある質問

無料ですか？

はい、すべての機能を無料で使えます。iPhone 版には広告が表示され、アプリ内の「広告を消す」（買い切り）で消せます。Windows 版に広告はありません。

Android や iPad、Mac でも使えますか？

Android・iPad でも使えます。3 台以上を同時につなぐこともできます。Mac 版は Mac App Store で公開予定です。

離れた場所の PC にも送れますか？

いいえ。AirBoard は同じ Wi‑Fi / LAN の中だけで動きます。そのぶん、コピーした内容が外のサーバーに残ることはありません。
