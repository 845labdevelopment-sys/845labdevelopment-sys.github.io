iPhone の写真を、ケーブルなしで Windows へ

同じ Wi‑Fi だけで送る · 2026年10月6日

iPhone で撮った写真を Windows の PC で使いたいとき、ケーブルをつなぐか、メールや LINE で自分に送ることが多いと思います。このページでは、ケーブルもクラウドも使わずに、同じ Wi‑Fi だけで iPhone の写真を Windows に送る方法を説明します。

よくある方法と、その手間

  • USB ケーブルで取り込む：ケーブルが手元にあれば確実ですが、取り込みの操作が毎回いります。
  • メールや LINE で自分に送る：手軽ですが、何枚も送ると手間が増え、写真が外のサーバーを通ります。
  • クラウドの写真サービスで同期する：自動で便利ですが、アカウントの設定が要り、写真はクラウドに上がります。

AirBoard で送る方法

AirBoard は、同じ Wi‑Fi（LAN）につながった端末どうしで、写真・ファイル・コピーした文を直接やり取りするアプリです。インターネット上のサーバーを通らず、アカウント登録もいりません。

準備（最初の 1 回だけ）

  1. Windows に Microsoft Store から、iPhone に App Store から AirBoard を入れます。
  2. Windows と iPhone を同じ Wi‑Fi につなぎます。
  3. iPhone で「Wi‑Fiで探す」を押すか QR コードを読み取って、PC を選びます。はじめての端末は、Windows 側で承認するとつながります。

写真を送る

  1. iPhone の AirBoard で「共有」タブを開き、「写真」を押します。
  2. 送りたい写真を選びます（何枚でも選べます）。
  3. Windows では、「ドキュメント」の中の AirBoard フォルダに保存されます。保存先は Windows 版の「設定」›「保存先」で好きなフォルダに変えられます。

写真以外のファイル（PDF など）は、「共有」タブの「ファイル」から同じように送れます。逆に Windows から iPhone へは、ファイルを AirBoard のウィンドウに落とすだけで送れ、iPhone では「ファイル」アプリの「このiPhone内 › AirBoard」に入ります。

iPhone では AirBoard を開いている間に送受信します。iOS の仕組み上、AirBoard が裏に回っている間は送ったり受け取ったりしません。送り終わるまで AirBoard を開いておいてください。

つながらないとき

会社・学校・ホテルの Wi‑Fi では、端末どうしの通信が止められていることがあります。そのときは Windows のモバイル ホットスポットや iPhone のインターネット共有でつなぐ方法を試してください。

よくある質問

無料ですか？

はい、無料で使えます。iPhone 版には広告が表示され、アプリ内の「広告を消す」（買い切り）で消せます。Windows 版に広告はありません。

写真はどこかに保存されますか？

送った写真は、送った先の端末（ここでは Windows の保存先のフォルダ）にだけ保存されます。インターネット上のサーバーには送られません。

コピーした文も送れますか？

はい。iPhone と Windows でコピペする方法をご覧ください。
