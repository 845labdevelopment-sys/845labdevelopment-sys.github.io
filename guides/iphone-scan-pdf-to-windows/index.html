紙の書類を、iPhone で PDF にして Windows へ

スキャナーなしで · 2026年11月25日

年末の片づけなどで、紙の書類をパソコンに残しておきたいことがあります。スキャナーがなくても、iPhone で撮るだけで PDF にして、同じ Wi‑Fi の Windows PC へ送れます。

用意するもの

  • AirBoard（Windows は Microsoft Store、iPhone は App Store から）
  • 同じ Wi‑Fi につながった Windows PC と iPhone

1. iPhone と PC をつなぐ（最初の 1 回だけ）

  1. Windows と iPhone で AirBoard を開き、同じ Wi‑Fi につなぎます
  2. iPhone の「共有」タブの上の行から「Wi‑Fiで探す」を押し、PC の名前を選びます（PC に出る QR を読み込んでもつながります）
  3. はじめての iPhone は、Windows に「接続の許可」が出ます。「許可」を押すとつながり、次からは聞かれません

2. 書類をスキャンして送る

  1. iPhone の AirBoard で「共有」タブを開き、「書類をスキャン」を押します
  2. カメラを紙に向けて撮ります。iPhone の書類カメラが紙の端を見つけて、まっすぐに整えます
  3. ページが続くときは、続けて撮ります。1 回で PDF に入るのは 10 ページまでです
  4. 撮り終えて保存すると 1 つの PDF になり、つながっている PC へ送られます

3. Windows で受け取る

PDF は、Windows の「ドキュメント」の中の AirBoard フォルダの received にある、その日の日付のフォルダ（例: 2026-11-25）に入ります。名前は Scan_20261125_103000.pdf のように、撮った日付と時刻になります。

保存先は、Windows の AirBoard の「設定」の「保存先」で変えられます。

送り終わるまで、iPhone の AirBoard を開いておいてください。iOS の仕組みで、ホームへ戻ると少しして通信が止まることがあります。AirBoard を前に戻すと、つなぎ直します。

うまくいかないとき

  • PC とつながっていないとき：スキャンした PDF は「送信待ち」に入ります。つながってから「送る」を押すと送れます。
  • 会社・学校・ホテルの Wi‑Fi：端末どうしの通信が止められていることがあります。Windows のモバイル ホットスポットや iPhone のインターネット共有を使う方法をお試しください。
  • 10 ページより多い書類：11 ページ目からは PDF に入りません。10 ページずつに分けて撮ってください。

年末の片づけでの使い方は、Zenn の記事にもまとめました：スキャナーを買わずに、紙の書類を iPhone から Windows へ PDF で送る

よくある質問

無料ですか？

同じ Wi‑Fi の中の機能は、すべて無料で使えます。スマホ版には広告が出ます。Windows 版に広告はありません。

書類はインターネットに上がりますか？

同じ Wi‑Fi の中で送るときは、PDF は iPhone から PC へ直接送られ、インターネット上のサーバーを通りません。アカウントもいりません。

Android でも使えますか？

はい。Android 版にも「書類をスキャン」があります（Google Play 開発者サービスが必要です）。

写真も送れますか？

はい。iPhone の写真をケーブルなしで PC へ送る方法をご覧ください。
